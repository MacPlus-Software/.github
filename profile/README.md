# MacPlus Software

Independent Mac apps for window management, the Dock and everyday productivity. Making Mac utilities since 2011.

[Website](https://noteifyapp.com/) · [All apps](https://noteifyapp.com/apps/) · [Free apps](https://noteifyapp.com/free-mac-apps/) · [Contact](https://noteifyapp.com/contact-us/)

## Windows and app switching

- **[Command-Tab Plus](https://noteifyapp.com/command-tab-plus/)** — advanced app and window switcher, a replacement for the built-in ⌘Tab.
- **[SuperTab 7](https://noteifyapp.com/supertab/)** — one ⌥Tab panel for apps, windows, clipboard history, recent documents and files.
- **[Quick Exposé 3](https://noteifyapp.com/quick-expose/)** — classic Exposé-style overview of every window and every desktop.
- **[WindowSwitcher 2](https://noteifyapp.com/windowswitcher/)** — every open window as a preview, with search and an app filter.
- **[Quick Exposé for Dock](https://noteifyapp.com/quick-expose/dock/)** — point at a Dock icon to spread out that app's windows.
- **[Quick Tab](https://noteifyapp.com/quick-tab/)** — full-screen app grid plus an ⌥Tab app switcher.
- **[Slides WM](https://noteifyapp.com/slides-ai/)** — fast keyboard window switcher with AI predictions.
- **[Stage View](https://noteifyapp.com/stage-view/)** — window previews for Stage Manager groups.
- **[MaxSnap](https://noteifyapp.com/maxsnap-mac-window-manager/)** — move, resize and arrange windows with hotkeys and gestures.
- **[Tab Finder](https://noteifyapp.com/tab-finder/)** — all open tabs from Safari, Chrome, Brave and Opera in one searchable list.

## Dock

- **[ActiveDock](https://noteifyapp.com/activedock/)** — customizable Dock replacement with window previews, groups and a start menu.
- **[DockView](https://noteifyapp.com/dockview/)** — live window previews when you hover a Dock icon.
- **[MultiDock](https://noteifyapp.com/multidock/)** — extra panels for the apps, files and folders you use together, alongside the Dock.
- **[Quick Dock](https://noteifyapp.com/quick-dock/)** — switch, hide or show the windows of Dock apps with number shortcuts.
- **[LaunchPanel](https://noteifyapp.com/launchpanel/)** — quick launcher for apps and files.

## Notes and productivity

- **[Tree Outliner](https://noteifyapp.com/tree-outliner/)** — text outliner with two views: a vertical list and a sideways tree. Also [on the web](https://treeoutliner.app/).
- **[NoteTree](https://noteifyapp.com/notetree/)** — notes app with nested folders, a rich editor and iCloud sync.
- **[PaperDay](https://noteifyapp.com/paperday/)** — one sheet a day: 1 big task, 3 medium, 5 small.
- **[Classic Commander](https://noteifyapp.com/classic-commander/)** — two-panel file manager with commander keys.
- **[ClipboardGrid](https://noteifyapp.com/clipboardgrid/)** — recent copies as large cards, one shortcut away.
- **[KeepNotes](https://noteifyapp.com/google-keep/)** — Mac desktop app for your Google Keep notes, with a quick-entry hotkey.
- **[Plus AI](https://noteifyapp.com/plus-ai/)** — write, improve, summarize and translate text in any app.
- **[ContextClip](https://noteifyapp.com/contextclip/)** — captures a window with its accessibility structure for AI coding agents.

## Focus and system utilities

- **[UnDistracted](https://noteifyapp.com/undistracted-self-control-2/)** — dims inactive windows and hides the Dock, menu bar and desktop icons.
- **[DeskCover](https://noteifyapp.com/deskcover/)** — hides desktop clutter behind a cover and highlights the active window.
- **[Mova](https://noteifyapp.com/mova/)** — language indicator next to the cursor; remembers the keyboard layout per app.
- **[FlexiNet](https://noteifyapp.com/flexinet/)** — menu bar switcher for macOS network locations.
